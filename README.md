# 🛰️ Antigravity Bilim & Teknoloji İstihbarat Ajanı (Android APK)

Dokümandaki 30 prestijli bilim, akademi, teknoloji ve enstitü kaynağını doğrudan Android telefonunuzda tarayan, **`a`, `b`, `c`, `d`, `e`, `f`, `k`, `y`** harflerine göre haberleri 1-5 ⭐ arasında derecelendiren ve anında **Word (`.docx`)** + **PDF (`.pdf`)** raporu üreten yerel Android uygulaması.

## 📦 APK Dosyası Nasıl Alınır ve Telefona Nasıl Yüklenir?

### Yöntem 1: Bilgisayara Hiçbir Şey Kurmadan (GitHub Actions ile 2 Dakikada APK Üretme) — ÖNERİLEN
1. Ücretsiz bir **GitHub** hesabı açın ve yeni bir depo (repository) oluşturun.
2. Bu klasördeki tüm dosyaları (`.github` klasörü dahil) o GitHub deposuna yükleyin (veya `git push` yapın).
3. GitHub deposunda üst kısımdaki **Actions** sekmesine tıklayın; **Build Android APK** iş akışı otomatik olarak başlayacaktır.
4. Yaklaşık 2 dakika içinde işlem tamamlandığında, sayfanın altındaki **Artifacts > `BilimTeknoloji-APK`** bağlantısına tıklayarak **`app-debug.apk`** dosyasını doğrudan telefonunuza indirin!

### Yöntem 2: Android Studio ile APK Derleme
1. Bilgisayarınızda **Android Studio**'yu açın.
2. **Open** diyerek `bilim_teknoloji_android` klasörünü seçin.
3. Gradle senkronizasyonu tamamlandıktan sonra üst menüden **Build > Build App Bundle(s) / APK(s) > Build APK(s)** seçeneğine tıklayın.
4. `app/build/outputs/apk/debug/app-debug.apk` dosyasını telefonunuza aktarın (WhatsApp, Google Drive veya USB kablosu ile).

## 📲 Telefonda Kurulum ve Kullanım

1. Telefonunuza indirdiğiniz **`app-debug.apk`** dosyasına dokunun.
2. Android güvenlik uyarısı gelirse: **Ayarlar > Bu kaynaktan izin ver** seçeneğini etkinleştirin ve **Yükle** butonuna basın.
3. Uygulamayı açın:
   - İstediğiniz kategorinin harfine (`a`, `b`, `c`, `d`, `e`, `f`, `k`, `y`) dokunun veya klavyeden yazıp **Raporla** butonuna basın.
   - Uygulama ilgili siteleri canlı olarak tarar, mükerrer haberleri temizler ve 1-5 ⭐ arasında puanlayıp 5'ten 1'e sıralar.
   - Rapor hazır olduğunda ekranda açılır; alttaki **📄 PDF Aç**, **📝 Word Aç** veya **📤 Paylaş** butonlarıyla raporu telefonunuzda görüntüleyebilir veya paylaşabilirsiniz!
